# Attribution and reuse boundaries

## Real datasets

- **OpenAlex**: public scholarly metadata, CC0. Snapshot source and query in `public/data/provenance.json`. Paper full texts and publisher figures are not copied. See https://docs.openalex.org/additional-help/faq.
- **NYC Landmarks Preservation Commission / NYC Open Data**: public administrative metadata. Governed by the provider's terms; this release does not relabel it CC0. Dataset: https://data.cityofnewyork.us/Housing-Development/Designated-and-Calendared-Buildings-and-Sites/ncre-qhxs. No landmark photographs are copied. Terms: https://opendata.cityofnewyork.us/overview/#termsofuse.
- **NASA EONET**: event metadata from the documented teaching snapshots. Observe original sources and attribution. https://eonet.gsfc.nasa.gov/docs/v3.
- **Natural Earth / world-atlas**: simplified map data for context, not legal boundaries. Natural Earth data are public domain; see https://github.com/topojson/world-atlas.
- **Zachary's Karate Club**: retained NetworkX built-in benchmark in the original notebook. It is a teaching example, not course participant data.

## Software

React, React DOM, Vite, D3, Three.js, topojson-client, world-atlas and Lucide retain their upstream licenses. Exact versions are in package-lock.json. Package documentation links and notebook dependencies are listed in the tutorial. Installation does not confer rights over all datasets loaded by a package.

## Reference interfaces

InstantMesh, TRELLIS, DeepSite, React Three Next, Threejs-Punk and Vercel's 3D event-badge article informed interaction patterns. Their code, logos, screenshots and model-generated content are not bundled or copied. Names are used only to identify the references.

## Original course material

The previous 38-idiom HTML atlas and prior course notebooks are included as course-owner-provided reference material. Keep their citations and provenance. Verify public-sharing rights before publishing materials beyond the authorized course audience. The package does not assert a new open-source license over those files.
